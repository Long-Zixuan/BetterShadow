# Better Shadow

Make the shadow soft and better  
## Install
1.Double click mcpack to import (or in the game: Settings ->Storage ->Resource Pack ->Import).  
2.Settings ->Global Resource Pack ->Activate Vanilla Light (also enabled in the archive).  
3.Settings → Video →  Graphic Mode → Check “Dynamic Visual Effects/Vibrant Visuals” .
